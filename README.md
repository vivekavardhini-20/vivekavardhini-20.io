## About the Project

This project contains the practical programs completed as part of the
Web Technology and Development course.

The website provides a main dashboard through which the HTML, CSS,
and JavaScript practical programs can be accessed separately.

Each practical program is available as an individual HTML file.

## Project Structure

- `index.html` – Main dashboard
- `html/` – HTML practical programs
- `css/` – CSS practical programs
- `javascript/` – JavaScript practical programs
- `assets/` – Common CSS files
- `README.md` – Project information

## How to Run

1. Open the main `index.html` file in a web browser.
2. Select HTML, CSS, or JavaScript Programs.
3. Select the required practical program.
4. Click **View Program** to open the program.
